# RAW Overlay Viewer — 專案計劃書

> 狀態：規劃中（v0.1 草案）｜最後更新：2026-09-30

## 1. 目標

做一個**免費、開源、輕快**的 RAW 瀏覽器，讓攝影師可以：

1. 快速逐張瀏覽一個資料夾內的 RAW 檔（上一張／下一張）
2. 自選兩張照片（A、B），把 A **半透明疊**在 B 上
3. 自行調整不透明度，直接看出兩張的差別（表情、焦點、構圖、動態）

### 為什麼要做

| 現有工具 | 缺點 |
|---|---|
| darktable / RawTherapee / digiKam | 能瀏覽、能並排，但不能半透明疊圖 |
| GIMP | 能疊圖層，但每次手動開檔，很慢 |
| nomacs | 靠「兩個視窗＋調視窗透明度」勉強做到，操作繁瑣，macOS 支援弱 |
| FastRawViewer / Photo Mechanic | 付費，且沒有疊圖比對 |

目前沒有一個工具同時做到「秒開 RAW」和「互動式半透明疊圖」。

## 2. 範圍

### 第一版要做（MVP）

- **格式：只支援 Sony ARW**
- 開啟資料夾，列出所有 `.ARW`
- 單張檢視，用 ← → 切換前後張，並預先載入前後幾張
- 底部縮圖列
- **比對模式**
  - 使用者自選 A、B 兩張（預設為目前這張和下一張，可改成任意兩張）
  - A 疊在 B 上，用滑桿調整 A 的不透明度（0–100%）
  - 快捷鍵：數字鍵 `1`–`9`、`0` 快速切換 10%–100%
  - 兩張同步縮放和平移（適合位置相同的比對）
  - 可以單獨拖動 A 的位置（照片構圖不同時，自己手動對到想比的地方）
- 顯示基本 EXIF：快門、光圈、ISO、焦距、拍攝時間

### 第一版不做

- 自動對齊（不假設同一構圖）
- 修圖、調色、匯出
- Sony 以外的 RAW 格式
- 評分、標籤、刪除檔案（v2 再考慮）

## 3. 技術設計

### 3.1 RAW 讀取策略：預覽優先

ARW 是 TIFF 結構，檔案內含相機產生的 JPEG 預覽圖。

| 階段 | 來源 | 速度 | 用途 |
|---|---|---|---|
| 縮圖 | 內嵌小縮圖 | 極快 | 縮圖列 |
| 一般瀏覽 | 內嵌 JPEG 預覽 | 快（只讀檔、不解 RAW） | 全螢幕瀏覽、疊圖 |
| 放大看細節 | 完整 RAW 解碼 | 較慢 | 100% 放大時才背景解碼 |

> 內嵌預覽的解析度因機型而異，需要實測 α7 系列、α6000 系列、RX100 等常見機型（見 §6）。

### 3.2 技術選型（提案）

| 層 | 選擇 | 理由 |
|---|---|---|
| 桌面框架 | **Tauri 2** | 跨平台（macOS / Windows / Linux），安裝檔小 |
| 後端 | **Rust** | 解析 ARW、抽預覽、快取，效能好 |
| RAW 解碼 | `rawler`（dnglab 的解碼庫）；備案 LibRaw 綁定 | 支援 Sony ARW，純 Rust 好打包 |
| 前端 | TypeScript + **WebGL**（或 Canvas 2D） | 疊圖用 GPU 混合，拖滑桿時即時更新 |
| EXIF | `kamadak-exif` 或直接解析 TIFF 標籤 | — |

替代方案：若只打算支援 macOS，可改用 Swift + Core Image（系統內建 RAW 解碼，最省事），代價是無法跨平台。

### 3.3 架構

```
┌──────────── 前端 (WebView) ────────────┐
│ 縮圖列 │ 檢視器(WebGL) │ 比對控制面板 │
└──────────────┬────────────────────────┘
               │ Tauri IPC / 自訂協定傳圖片
┌──────────────┴──────── 後端 (Rust) ────┐
│ 資料夾掃描 → ARW 解析 → 預覽抽取       │
│ 背景解碼佇列 → 記憶體 LRU 快取         │
└────────────────────────────────────────┘
```

### 3.4 疊圖原理

```
輸出 = A × α + B × (1 − α)      α = 使用者設定的不透明度
```

在 fragment shader 中計算，A 有自己的位移量（使用者拖動），B 固定；縮放和平移對兩者同步套用。

## 4. 里程碑

| 版本 | 內容 | 完成條件 |
|---|---|---|
| **M0** 專案骨架 | Tauri 專案、CI（三平台 build）、授權、貢獻指南 | CI 綠燈 |
| **M1** ARW 讀取 | 抽出內嵌預覽和 EXIF，建立測試樣本 | 測試機型都能讀出預覽 |
| **M2** 瀏覽器 | 開資料夾、縮圖列、←→ 切換、預載 | 切換下一張 < 100ms（預覽已快取） |

| **M4** 完整解碼 | 放大時背景解完整 RAW | 放大到 100% 時細節清晰 |
| **v0.1.0 發佈** | 三平台安裝檔上架 GitHub Releases | — |

之後可以考慮（v0.2+）：Difference 差異模式、A/B 閃爍切換、分割線對比、評分和篩選、支援更多品牌 RAW。

## 5. 操作設計（草稿）

| 按鍵 | 動作 |
|---|---|
| ← / → | 上一張／下一張 |
| `A` / `B` | 把目前這張設為 A 或 B |
| `C` | 進入／離開比對模式 |
| `1`–`9`, `0` | 不透明度 10%–100% |
| 滑鼠滾輪 | 縮放（同步） |
| 拖曳 | 平移（同步） |
| `Shift` + 拖曳 | 只移動 A |

## 6. 風險與待確認

| 風險 | 對策 |
|---|---|
| 各機型內嵌預覽解析度不同，有些偏小 | M1 實測；太小時自動改用完整解碼 |
| 壓縮 ARW（lossy / lossless）解碼支援度 | 以 rawler 測試，不行就改用 LibRaw |
| 測試用 RAW 樣本的版權 | 使用自己拍的或 raw.pixls.us 等授權明確的樣本，不放入 repo，用下載腳本取得 |
| WebView 傳大張圖片的效能 | 用 Tauri 自訂協定直接傳二進位，不用 base64 |
